# Roadmap and Open Decisions

Updated: 2026-10-09. Targets are intentions, not commitments.

## Phase 1 — Homecoming (target October 10–11, 2026)
- [ ] Publish new static, accessible homepage emphasizing Auralethi's community mission.
- [ ] Introduce Free to Meet / Safe to Become; distinguish current vs planned initiatives.
- [ ] Add simple splash intro: name + three thematic words, skip/reduced motion.
- [ ] Restore/maintain routes: About, Research, Projects and a basic News/Our Journey page.
- [ ] Keep useful existing AI safety research reachable.
- [ ] Validate mobile, keyboard access, links, content and deployment on GitHub Pages.

## Phase 2 — Durable publication
- [ ] Define content metadata and project status model.
- [ ] Add weekly public progress posts with owner review.
- [ ] Test end-to-end drafting, PR approval, merge and publish.
- [ ] Verify Squarespace/domain renewal and Google Workspace/email configuration.
- [ ] Write organization bios/project descriptions with documented claim provenance.

## Phase 3 — Visual Studio / component architecture
- [ ] Decide whether to adopt static Blazor WebAssembly or remain static HTML with components/build tools.
- [ ] Establish reproducible solution/build/test workflow, preferably with zero new hosting cost.
- [ ] Implement reusable project cards, status badges and navigation.
- [ ] Add richer motion with reduced-motion and accessibility defaults.

## Later phases
- [ ] Jix optional visitor guide, pending backend, privacy and cost design.
- [ ] Deeper interactive project maps and program participation flows.
- [ ] Dedicated infrastructure once available and justified.

## Open decisions
- Final splash words (candidate: Community, Belonging, Possibility).
- Exact page names and navigation.
- Visual brand palette, animation behavior and copy approval.
- Which project achievements are approved for public disclosure.
- Where to host future Jix API safely and affordably.

## Definition of done for Phase 1
Public website communicates purpose, two pillars, actual vs planned status, accessible navigation, working About and Research links, published news page scaffold, and verified deployment. No fabricated operational claims or forced AI interaction.
